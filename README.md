# محاكاة تقطير الماء
**PhysicLabDZ**

محاكاة تفاعلية لتقطير الماء الطبيعي، تعمل في المتصفح دون إنترنت بعد أول زيارة.

## الملفات
- `index.html`: الكود مضغوط (Deflate) ويُفكّ عند التشغيل
- `bg.jpg`: صورة الخلفية
- `sw.js`: التخزين المسبق للعمل دون اتصال
- `manifest.json` + `icon*`: التثبيت كتطبيق (PWA)

## التشغيل
يلزم خادم HTTPS أو localhost (لا يعمل `sw.js` من `file://`).

### GitHub Pages
1. أنشئ مستودعًا باسم `distillation` وارفع محتويات هذا المجلد.
2. Settings ← Pages ← Branch: `main` / root.
3. الرابط: `https://physiclabdz.github.io/distillation/`

## العمل دون اتصال
- يُطلب «تخزين دائم» تلقائيًا (`navigator.storage.persist()`) لمنع مسح الكاش.
- للحصول على أفضل فرصة للقبول: ثبّت الموقع كتطبيق (أيقونة التثبيت في شريط العنوان).
- عند تعديل أي ملف: غيّر رقم `V` في `sw.js` (مثلًا `distill-v2`).

## ملاحظة
الضغط يحجب الكود عن القراءة العابرة فقط، وليس تشفيرًا.
